使用以下命令将目标分支“假合并”（synthetic merge）到当前分支：

git merge -s ours <目标分支名>
git merge -s ours 1.21.11 -m "Synthetic merge to skip 1.21.11 changes"

作用：
- 创建一个 merge commit
- merge commit 的两个 parent 分别是当前分支和目标分支
- 但 merge 结果完全采用当前分支内容
- 不会引入目标分支的任何代码变更

效果：
Git 会认为两个分支已经合并过。
后续再次 merge 时，将以本次 merge commit 作为共同祖先，
从而跳过目标分支此前的所有提交差异。

适用场景：
当某些提交仅适用于目标分支对应的 Minecraft 版本，
且不希望这些改动进入当前分支时，可使用该方法。

反编译：

java -jar $vf -dgs=1 输入.jar 输出目录/
java -jar $cfr 输入.jar --outputdir 输出目录/
